# 🎓 网络学院学习小助手

> 本地网页版多账号自动学习工具：批量账号 + 课程链接，自动登录、自动播放、实时日志。

## 状态：✅ 可用（2026-08-20 减包改造完成）

- **位置**：`C:\Users\zafki\OneDrive\工作\工作工具\网络学院学习小助手`
- **技术栈**：Node.js 20.19.3（内置）+ Express + Playwright 1.62.1，纯本地运行，端口 3000（被占用自动换）
- **功能**：多账号批量刷课、SIA 中石化网络学院模板、自动/手动登录、播放进度日志（30s/10%）、单节最长、定时滚动防掉线、视频断点续播自动识别

## 平台机制（SIA 关键文本格式）

| 级别 | 格式 | 含义 |
|---|---|---|
| 课程级 | `完成进度：50% 学习状态： 未通过` | 整课进度（.course-progress 元素） |
| 课时级 | `第1课时:xxx 18% 已学：6分钟 通过：33分钟 状态:未通过` | 已学=累计学习时长，通过=视频时长，状态=是否通过 |

- 平台判定「通过」= 视频播放到 100%（断点续播，重开页面 currentTime 从上次位置起播）

## 2026-08-20 修复与改造记录

### 1️⃣ Bug 修复：已通过课程重头学
- **根因**：worker 只用本次会话 `video.currentTime` 判完成，忽略平台累计学习时长 → 已通过课程重开页面归零从头刷
- **修复**（worker.js）：
  - 进入课程**首检**：课程级 100%/状态已通过，或**全部课时**已学≥通过/状态已通过 → 跳过本课，自动进入下一课程/账号（计入已完成）
  - 播放中**每 30s 复核**：累计时长达标即提前完成
  - 日志带原因，如 `全部 1 个课时累计学习时长已满/已通过（33分0秒≥33分0秒(未通过)）`
- **验证**：单测 16/16 + 本地模拟页 e2e 8/8 + **真实 7 账号验证**（3 个已通过正确跳过、4 个未学完不误跳、登录 7/7 成功）

### 2️⃣ 浏览器减包：内置 Chromium → 系统 Edge
- **背景**：内置 Chromium 699MB，是 zip 最大部分
- **方案**：Playwright `channel` 通道调用系统浏览器；任务配置新增「浏览器」下拉（auto/系统Edge/系统Chrome/内置Chromium），默认 auto = 优先系统 Edge → 回退内置
- **效果**：zip **344.7MB → 38.3MB（-89%）**；实测 Edge 151 全链路（登录+检测+播放）正常
- **配套**：smoke-test.mjs / start.bat / check-env.bat 均改为「内置 Chromium 或系统 Edge 任一存在」

## 配置手册（data\tasks.json）

任务 = 一个平台（如 SIA）+ 一批账号 + 一批课程，界面里直接增删改，底层存这个 JSON。

| 配置项 | 含义 | 示例 |
|---|---|---|
| `name` | 任务名 | `SIA 中石化网络学院` |
| `loginUrl` | 登录页地址 | `https://sia.sinopec.com/learn/` |
| `loginMode` | 自动/手动登录 | `auto` |
| `headless` | 无头模式 | `true` |
| `videoSelector` | 视频元素选择器 | `video` |
| `maxMinutesPerLesson` | 单节最长播放分钟（防卡死） | `60` |
| `autoNext` | 播完自动切下一课时 | `false` |
| `keepAlive` | 定时滚动防掉线 | `true` |
| `accounts[]` | 账号列表（用户名/密码/启用开关） | ⚠️ 明文存本机，**不要外传** |
| `courses[]` | 课程列表（名称 + 播放页 URL） | `https://sia.sinopec.com/page/#/vedio/play?...` |

**操作要点**：
- 加账号：复制一个 `accounts` 条目改用户名密码，`enabled` 置 `true`
- 加课程：把 SIA 课程**播放页 URL**（`.../vedio/play?...`）粘进 `courses`，`name` 随意
- 改完保存，刷新网页页面生效（无需重启服务）
- 登录选择器（用户名/密码/登录按钮）各平台不同，换平台时在任务配置里改 selector
