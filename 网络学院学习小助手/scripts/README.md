# 网络学院学习小助手（多账号版）

一个本地运行的网页小工具：批量导入多个账号和课程链接，自动登录、自动播放当前课程页面，并在网页里查看实时日志。

## 启动

### Windows 一键启动

1. 在 Windows 10/11 x64 上把 `网络学院学习小助手-windows.zip` 完整解压到本地目录。
2. 双击 `start.bat`，会自动打开工具页面（默认 `http://127.0.0.1:3000`，端口被占用时自动用实际端口打开）。
3. 停止服务：关闭弹出的 `网络学院学习小助手服务` 窗口。

这个包内置 Node.js 20.19.3 和全部运行依赖；浏览器默认**优先调用系统 Edge**（Windows 10/11 自带，无需安装），找不到 Edge 时自动回退内置 Chromium（如已打包）。使用“手动登录”模式时需要 Windows 桌面会话，运行刷课任务则要求本机可以正常访问你填写的课程网站。

如果启动异常，先双击 `check-env.bat` 确认组件齐全，再双击 `smoke-test.cmd` 测试浏览器能否启动；最后把两个窗口的输出和 `网络学院学习小助手服务` 窗口里的日志发出来。

### macOS 一键启动

1. 双击 `start.command`（如果被系统拦截，右键选择“打开”即可）。
2. 脚本会自动检查 Node.js、安装缺失依赖和 Chromium，然后启动服务并打开浏览器。
3. 停止服务：关闭 `start.command` 所在终端窗口，或按 `Ctrl+C`。

macOS 版使用本机 Node.js 和 Playwright，需要已安装 Node.js 20 或更高版本，首次运行会联网安装依赖和下载 Chromium。

### 通用启动（macOS / Linux / Windows 命令行）

```bash
npm install
npm start
```

启动后浏览器打开 `http://127.0.0.1:3000`。如果端口被占用，服务会自动换到下一个可用端口并在终端打印实际地址。

首次启动会自动创建一个“SIA 中石化网络学院”模板任务，已按平台实际结构配置：

- 登录地址：`https://sia.sinopec.com/learn/`
- 登录入口按钮：`button:has-text("登 录")`
- 账号输入框：`input[placeholder="请输入统一账号"]`
- 密码输入框：`input[placeholder="请输入密码"]`
- 登录按钮：`button:has-text("立即登录")`

SIA 新版登录是首页点击“登 录”后弹出的对话框，模板同时兼容“请登录”“重新登录”等入口；如果平台以后改版，可直接调整 `data/tasks.json` 里对应字段。

登录后课程播放页使用 `/page/#/vedio/play` 路由，视频由 HTML5 播放器渲染为 `video` 元素，所以“本次运行课程”里直接粘贴播放页链接即可，例如：

```text
https://sia.sinopec.com/page/#/vedio/play?domainId=xxx&courseId=xxx
```

每个账号的运行顺序固定为：先打开登录首页并确认登录成功，再逐个载入课程页。登录首页留空时，SIA 会自动使用 `https://sia.sinopec.com/learn/`，其他平台会自动使用课程链接的站点根路径。

## 使用方法

1. 新建任务；SIA 模板已带登录首页，其他平台可留空登录首页，由课程链接自动推导。
2. 添加账号（一行一个账号密码）。
3. 每次运行前，在“本次运行课程”里粘贴课程链接，每行一个；也可以把常用课程先保存到课程列表。
4. 点击“启动任务”，在运行日志里查看进度，随时可以停止。

登录表单和视频元素会自动识别，SIA 的登录配置已内置在任务里。默认只刷当前页面，视频播完本页就算完成。运行日志每 30 秒或每 10% 输出一次播放进度（已播时长/总时长/百分比），视频结束或接近结束时输出“本节播放完成”。
如果登录后第一次进入课程被平台跳回主页，程序会自动重新进入课程页，无需手动操作。

课程是否“已通过”只看课程页右侧进度面板的“完成进度”，进度显示为 100% 才计入已通过；课时列表里单独的“状态:通过”不会把整门课判定为已完成。

登录方式可选：

- 自动填写：程序自动输入账号密码并点击登录，适合没有验证码的平台。
- 手动登录：程序弹出真实浏览器，自己完成登录后，回到网页点击“已登录，继续”。

账号和课程配置保存在 `data/tasks.json`，只在本地存储。

## 配置项

| 配置 | 说明 |
| --- | --- |
| 登录地址 | 登录页 URL，SIA 模板已填 `https://sia.sinopec.com/learn/` |
| 浏览器 | 自动（优先系统 Edge，无则用内置 Chromium）/ 系统 Edge / 系统 Chrome / 内置 Chromium |
| 隐藏浏览器窗口 | 开启后使用无头模式，不显示浏览器 |
| 定时滚动防掉线 | 每 60 秒小幅滚动页面，避免平台判定长时间无操作 |
| 单节最长 | 单节超过该时间自动换下一节 |

请仅对自己有权操作的账号使用，并遵守目标平台的使用规则。
