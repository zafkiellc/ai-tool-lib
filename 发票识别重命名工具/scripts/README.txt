 发票识别重命名工具 1.0
========================

用途
----
批量识别电子发票 PDF：
1. 从发票备注栏识别“xx加油站 / xx充电站”和项目内容；
2. 识别价税合计总金额和发票号码；
3. 按发票号码把 PDF、XML、单文件 ZIP 配对；
4. 统一重命名为“备注名_总金额_发票号”格式（可在界面里修改模板）。

支持的文件
----------
- PDF 电子发票（文字版，非扫描图片）
- XML 数电发票数据文件
- ZIP 压缩包：单文件压缩包会整体重命名；含多张发票的混合压缩包会解压到
  “原压缩包名_重命名结果”文件夹，并把里面的 PDF/XML 重命名，其余文件保留。

Mac 启动
--------
双击 “启动工具.command”，或直接双击 “mac版/发票识别重命名工具.app”。
如果系统提示无法打开，请右键选择“打开”，在弹窗中确认一次。
自动适配 Apple 芯片与 Intel 芯片 Mac。
请把 .app 放在整个工具文件夹内使用，不要单独移走。

Windows 启动
------------
双击 “启动工具.bat”。
首次运行若出现防火墙/Windows Defender 提示，允许本机 127.0.0.1 端口即可。
如果窗口一闪而过：请先把整个文件夹从压缩包中完整解压出来再运行，并确认
runtime\win\node.exe 与 app\server.js 都存在；新版启动脚本结束后会停在窗口等待关闭。

使用方法
--------
1. 点击“选择文件夹”或“选择文件”，也可以直接粘贴路径；
2. 点击“开始扫描”，预览识别结果；
3. 黄色“需确认”的发票请人工核对站点/项目，可直接在“新文件名”里修改；
4. 选择“原位置重命名”或“输出到文件夹”；
5. 点击“执行重命名”，查看执行记录。

重复执行
--------
默认开启“重复执行时自动跳过已存在的相同文件”：
- 重复点击执行不会再次复制生成 “名称 (2)” 这类重复文件；
- 只有内容完全相同的目标文件会被跳过，不同内容的文件仍会保留为新文件；
- 不需要此功能时，取消勾选该选项即可恢复原来的追加行为。

命名模板
--------
默认模板：{remark}_{amount}_{invoice}
可用变量：
  {remark}  备注名（站点+项目）
  {station} 站点
  {project} 项目
  {amount}  总金额
  {invoice} 发票号码

示例（默认模板）
----------------
陈家咀加油站配电柜线路故障维修.pdf
  -> 陈家咀加油站配电柜线路故障维修_1200.00_26422000002825202451.pdf

陈家咀加油站配电柜线路故障维修.zip
  -> 陈家咀加油站配电柜线路故障维修_1200.00_26422000002825202451.zip

汉阳混合压缩包内的 PDF/XML
  -> 升官渡加油站监控维修_350.00_26422000002848191631.pdf / .xml
  -> 汉洪东加油站空调维修_2450.00_26422000002848191901.pdf / .xml

说明
----
- 工具为便携版，Node.js 运行环境已内置，无需安装任何软件；
- 本版本面向文字版电子发票，扫描图片发票需要先进行 OCR；
- 执行前会再次确认，请保留好原始数据或使用“输出到文件夹”模式。
