督导填表助手 · 便携版（傻瓜式，双击即用）
==============================================

【这是什么】
这是一个「完全不需要安装任何东西」的便携版。
文件夹里自带了一套精简的 Python 运行环境（python-build-standalone），
拷到任何一台 Windows 电脑上都能直接运行，不需要装 Python、不需要装 WorkBuddy、
不需要装任何浏览器插件。

【使用步骤（三步）】
1. 把整个「巡站724_便携版」文件夹复制到电脑任意位置
   （路径含中文/空格本版也已兼容，但如个别环境异常，建议放纯英文短路径）。
2. 双击「启动.vbs」（推荐，完全无命令行窗口）
   -> 屏幕右下角「系统托盘」出现一个蓝色「表」图标，浏览器自动打开 http://127.0.0.1:8721。
   -> 「启动.bat」也可双击（效果一致，会再调起 vbs），但 vbs 更干净、无任何黑窗闪烁。
   若浏览器没自动打开：右键托盘图标 ->「🌐 打开网页」，或手动在地址栏输入
   http://127.0.0.1:8721
3. 开始使用。

【关闭服务】
- 右键系统托盘蓝色图标 ->「❌ 退出服务」
- 或在操作网页内点「退出服务」按钮
（用 pythonw + vbs 启动，无任何命令行窗口，只用托盘图标管理启停。）

【关于「托盘模式空白页」的修复说明】
旧版在 pythonw（无控制台）下，http.server 每处理一条请求都会写日志到 sys.stderr，
而 pythonw 的 stderr 为 None，导致每条请求抛异常、连接被中断，浏览器拿到 0 字节 → 空白页；
控制台（调试模式）因有真实 stderr 所以正常。本版已做两道修复：
  ① 启动期把 None 的 stdout/stderr 重定向到 server_debug.log；
  ② log_message 改为写调试日志（带异常保护），不再触碰 sys.stderr。
因此无论用 vbs 还是 bat 启动，托盘模式都不再空白。沿用「调试模式.bat」仍可看黑窗排错。

【随机补足功能（新增）】
- 在左侧「📝 手工记录」粘贴你的现场检查问题（每行一条）。
- 当手工条数不足 10 条时，点「🔍 开始匹配」会自动从《随机问题清单.xlsx》随机补足到 10 条；
  也可随时点「🔢 随机补足」手动补足。
- 补足规则：
  ① 尽量不与你手工录入的内容重复（相似即跳过）；
  ② 同一「一级分类」最多补足 3 条，自动分散到不同分类，减少同类重复。
- 补足的条目带「🤖补充」标记，可单独删除（删除只移走该补足条目，不影响你的手工内容）。
- 想关闭自动补足：取消勾选「手工不足 10 条时自动随机补足」。

【扩充随机清单（随时上传）】
- 在左侧「📝 手工记录」下方有「➕ 扩充随机清单」面板，可随时把新内容加入随机池：
  ① 选文件：点「选择文件」上传 .xlsx / .xls / .csv / .txt
     （支持带「序号列 / 一级分类列」的巡检清单格式，会自动跳过表头、丢弃序号列、取最长文本作为问题描述）；
  ② 或粘贴文本：文本框逐行粘贴，每行一条；如用 Tab 分隔第二列，可作「一级分类」；
  ③ 模式：默认「追加」（保留已有），选「替换」则只保留本次上传内容；
  ④ 点「📥 上传补充」，成功会显示「已追加 N 条」。
- 上传内容写入本目录「随机问题清单_用户补充.xlsx」，与主清单（随机问题清单.xlsx）合并后用于随机补足；
  主清单始终保持不动，你的补充独立存放，可反复上传扩充。
- 去重：与已有清单（主+补充）相似的条目会自动跳过，不会重复堆积。
- 你给的「巡站问题ai.xlsx」已作为补充导入（54 条），现在随机补足的池子已包含这些内容。

【自定义随机清单】
- 本目录下的「随机问题清单.xlsx」就是要补足的内容来源（已内置 44 条示例；你上传的补充另存于
  「随机问题清单_用户补充.xlsx」，二者合并后用于随机补足）。
- 默认只有一列（问题描述），程序会按关键词自动归入「一级分类」
  （加油区及设备 / 厕所及清洁 / 标识及宣传 / 便利店及商品 / 员工及服务 / 台账及记录 / 安全及消防 / 其他）。
- 如需自己控制分类：在 xlsx 第二列填上「一级分类」即可，程序优先用你填的分类。
- 改完 xlsx 保存后无需重启，下次点「随机补足」即生效（程序带缓存，按文件修改时间刷新）。

【常见问题】
Q: 双击「启动.bat」后什么都没出现 / 没看到托盘图标？
A: 可能是杀软拦截了 pythonw.exe。先把整个文件夹加入杀软白名单；
   再用「调试模式.bat」双击，会弹出黑窗口并直接显示启动日志与报错，便于排查。
   （调试模式会显示命令行窗口，仅供排错，平时请用「启动.bat」。）

Q: 网页空白？
A: ① 确认右下角托盘有蓝色「表」图标（说明服务在跑）；
   ② 浏览器地址栏是不是 http://127.0.0.1:8721；
   ③ 按 F5 刷新页面；
   ④ 仍空白：右键托盘 ->「📂 打开数据目录」，查看 server_debug.log 最后几行发给开发者。

Q: 和之前的发布版 / 打包版(server.exe)有什么区别？
A: 打包版在某些电脑上被防火墙/杀软拦截导致空白页面，排查困难。
   便携版绕过所有打包问题，直接用 Python 解释器跑源码，和非打包版完全一致，稳定可靠；
   本版进一步用「托盘 + pythonw」彻底隐藏了命令行窗口。
