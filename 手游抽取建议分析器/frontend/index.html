🎯 抽卡规划（保底计算 · 优先级 · 对比 · 导出）

🎲 保底/概率计算
📊 抽取优先级排序
🔬 多角色对比
🎫 抽卡记录
📤 导出/分享
概率模型：角色池基础 0.6%/抽，第 74 抽起线性软保底（每抽 +6%），第 90 抽必出； 武器池基础 0.7%/抽，第 63 抽起 +7%，第 80 抽必出。参数为各游戏通用官方公示值，结果仅供规划参考。
优先级分 = 结论权重（必抽100 / 推荐70 / 纯XP30 / 观望40 / 不推荐15 / 数据不足10） + 置信度(0~1)×20（若有 AI）。按分数降序，辅助跨角色预算分配。
一键导入：先在游戏内打开一次「抽卡记录」页面（原神 / 星穹铁道 / 绝区零 支持），复制浏览器地址栏的完整链接（含 getGachaLog&authkey=…），粘贴到下面点「导入」即可自动分页拉取。 authkey 有时效，过期后需重新打开一次游戏内抽卡记录页复制新链接；需在可访问米哈游接口的网络（家庭宽带）下运行。 鸣潮 / 终末地 / 异环 暂无官方抽卡记录接口，不支持导入。
