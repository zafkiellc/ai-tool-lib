# 中石化汉阳片区损耗分析 —— 口径与方法参考

> 本文件为该 Skill 的权威方法说明。所有结论数值均来自 2026 年 7-8 月武汉汉阳片区真实数据，
> 经 `scripts/analyze_loss.py` 复算；换月份/换站点时脚本会自动重算，请勿硬编码下表数值。

## 1. 数据源与字段

### 进油验收报表（.xls，Sheet1）
- **表头行不固定，必须自动探测**：本数据集实测 7月文件表头在第 2 行（0 索引=1），8月文件表头在第 1 行（0 索引=0）。脚本 `load_xls` 扫描前 5 行、按关键字段（油品/实发温度/验收时间/损溢率Vt）命中数自动定位表头行，**勿硬编码行号**。
- 关键字段（列名含空格与全角括号，用子串匹配）：
  - 油站名称、`油品`(7月) / `油品名称`(8月) —— 注意优先匹配 `油品名称`，否则会被 `油品代码` 列截胡
  - `实发温度`（油库发油时油温）、`卸前油温(°C)`、`卸后油温(°C)`
  - `损溢率(‰)`（非 Vt 体积口径，高温下易转正）、`损溢率Vt(‰)`（Vt=20°C 标准体积修正口径，**相关性分析以它为准**）
  - `卸前升数(L)`、`卸后升数(L)`、`卸前油高(mm)`、`卸后油高(mm)`
  - `验收时间`（格式 `2026-07-31 23:40:5`，用正则提取小时）
- 陷阱：列名含空格/全角括号；Excel 长数字（出货单号）被读成 float，须 `str()`；`油品代码` 列也含"油品"子串，匹配油品列时须优先 `油品名称`。

### 损耗排名（.xlsx，多 sheet）
- `综合排名`：排名（按损耗率升降序，负损耗在前）、站名、同期/上月/本月销售与损耗率、同比、目标损耗率
- `汽柴排名`：汽油/柴油当期、同期、上期损耗透视
- `当期数据`：逐站×逐油品明细，列：油站(2)、油品名称(4)、总计=销售(8)、当期损耗(23)、损耗率(24)
  - **列索引以表头为准用子串动态取**（`油站`/`油品名称`(回退`油品`)/`总计`/`当期损耗`），勿硬编码
- 参考线（"平均线"）：全站汽油综合损耗率加权均值（Σ损耗/Σ销售×1000）

## 2. 核心口径规则（重要，错一个就误导）

1. **汽油/柴油必须分开**：柴油常为负损耗（盘盈，约 -1.6‰），显著稀释汽油损耗。本数据集全品口径 0.62‰(7月)/1.19‰(8月) vs 汽油口径 1.35‰(7月)/2.17‰(8月)，差异即来自柴油盘盈。综合分析只用汽油，柴油单独列示。
2. **未满月数据严禁比损耗量绝对值**：8月报表若只到月中（销售≈整月 1/3），直接比损耗量（6693 vs 7604L）会得出"损耗下降"的错误结论。必须用**损耗率(‰)** 或**日均损耗**。
3. **损耗率方向**：排名表正值=损耗，负值=降耗/盘盈（表头"负为降耗"）。
4. **验收损溢率Vt 是温度修正后**的单笔损溢率（‰），负值=损耗、正值=溢余，做温度/时段/罐位相关性最可靠；非 Vt 的 `损溢率(‰)` 在高温下因体积膨胀转正，不能代表真实损耗改善。
5. **高温油品体积膨胀效应**：体积口径验收损溢率在 8月高温时整体转正（"溢余"）是物理膨胀，非真实降耗——以 Vt 口径为准解读。

## 3. 分析维度与方法（结论参考：2026年7-8月武汉汉阳）

| 维度 | 方法 | 本数据集结论 |
|---|---|---|
| 油品拆分 | `当期数据` 按油品名含"汽油"/"柴油"分组 | 汽油 7月1.352‰→8月2.170‰（+60%）；柴油 -1.59~-1.63‰ 盘盈 |
| 温度 | 验收报表实发/卸前/卸后温度均值 | 8月(截至17日) 比7月高：实发 +1.5°C(28.2→29.7)、卸前 +2.2°C(26.5→28.7)；8/1-12 峰值均值30.6°C，8/13-17 回落至27.5°C |
| 温差 | 卸前油温-实发温度，与损溢率Vt 做 Pearson 相关 | r≈0.20-0.23 弱正相关；两月温差 -1.69(7月) vs -0.98(8月)，非主因 |
| 卸油时段 | 按验收时间小时分 凌晨/上午/午后/夜间，对比 Vt | 午后(12-18)最差；7月 午后-0.93/上午-0.42/夜间-0.52；8月 午后-0.44/上午+0.06/夜间+0.01 |
| 天气 | Open-Meteo 逐日，最高温≥35°C 分高温/非高温日 | 8月(截至17日) 高温日 8/17=47%（8/1-12 子集曾达 8/12=67%）；高温日比非高温日 Vt 损耗大 0.4~1.3‰ |
| 天气×时段 | 按日高温标记 × 时段桶聚合 Vt | 8月：高温×午后 -0.96、高温×上午 -0.81、高温×夜间 -0.34；非高温×上午 +0.63、非高温×午后 +0.05、非高温×夜间 +0.28 |
| 罐位 | 卸前/卸后升数、油高 vs 损溢率Vt 相关（卸前升数 p25/p75 分低/中/高罐位） | \|r\|≤0.09 无实质相关（卸前升数 r≈+0.07、卸后 -0.05、油高 +0.08）；主动配送下罐位不可控，不作治理抓手 |

## 4. 天气数据获取（Open-Meteo，无需密钥）

```
https://archive-api.open-meteo.com/v1/archive?latitude=30.59&longitude=114.30&start_date=YYYY-MM-DD&end_date=YYYY-MM-DD&daily=temperature_2m_max,temperature_2m_min,temperature_2m_mean,precipitation_sum,relative_humidity_2m_mean,weather_code&timezone=Asia%2FShanghai
```
- 武汉坐标：30.59, 114.30（换站点用 `--lat/--lon`）
- weather_code：0=晴 1=晴间多云 2=多云 3=阴 51/53/55=毛毛雨 61/63/65=雨 80-82=阵雨 95=雷暴
- **本地网络受限（WinError 10054）时**：用 WebFetch 工具抓取该 JSON → 落盘为 weather.json → 脚本加 `--weather weather.json` 传入。脚本联网失败会自动跳过天气段并提示，其余分析照常。
- 样例：`assets/weather_sample_wuhan_2026-08.json`（本数据集 8/1-18 天气，可离线复用）。

## 5. 输出模板（HTML 报告章节，深色主题，红=损耗高/恶化，绿=降耗/改善）

1. 关键结论卡片（汽油率、后五站点、高温日占比、温差、罐位r）
2. 汽油 vs 柴油口径对比表（显式说明柴油盘盈稀释效应）
3. 汽油口径站点排名 + 后五站点对比表
4. 武汉本地天气（逐段，标注高温日与峰值段）
5. 卸油时段 × 天气交叉表
6. 高罐位相关性验证（分桶+Pearson r，结论无实质相关）
7. 调优建议：季节特性（盛夏防蒸发+错峰/秋冬防呼吸+计量校核）· 汽柴油站点特性（纯汽油蒸发治理/混合站分开考核）· 全站点通用（小批量多批次、避开12-18时、单量≤2天销量）· 超标站点分层（A档连续超标≥3‰ / B档）
