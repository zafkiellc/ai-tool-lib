# 中石化汉阳片区损耗分析

## Overview

分析加油站进油验收报表（.xls）与损耗排名（.xlsx），输出：①汽油/柴油口径拆分与真实损耗率；②站点排名与后五站点；③温度/温差/卸油时段/天气/罐位与损耗的相关性；④季节·站点特性·超标站点分层的调优建议。产出 HTML 可视化报告。

## 工作流

### Step 1 确认数据与口径
- 输入通常为多个月份文件：`进油验收报表（YYYYMM01-YYYYMM31）*.xls` + `X月损耗排名.xlsx`
- **立即确认报表是否满月**：满月天数=31/30，未满月（如当月仅到12日）必须用损耗率(‰)/日均，严禁直接比损耗量绝对值（会误判为"下降"）
- 查阅 `references/analysis_method.md` 获取字段映射、列索引陷阱、口径规则

### Step 2 运行分析脚本
```bash
python scripts/analyze_loss.py \
  --files "check_7m:D:/下载/进油验收报表（20260701-20260731）*.xls,check_8m:D:/下载/进油验收报表（20260801-20260831）*.xls,rank_7m:C:/.../7月损耗排名.xlsx,rank_8m:C:/.../8月损耗排名.xlsx" \
  --weather assets/weather_sample_wuhan_2026-08.json --out stats.json
```
- 标签规则：`check_*`=验收报表(必须.xls，用xlrd读取)，`rank_*`=排名xlsx
- **表头行自动探测**：验收报表 7月表头在第2行(0索引=1)、8月在第1行(0索引=0)，脚本扫描前5行自动定位，**无需指定行号**
- **油品列优先匹配`油品名称`**：7月叫`油品`、8月叫`油品名称`，且报表存在`油品代码`列会截胡，脚本已处理
- `--weather`：本地离线可直接用 `assets/weather_sample_wuhan_2026-08.json`；联网获取用 Open-Meteo（受限网络 WinError 10054 时改 WebFetch 抓 JSON 落盘后传入）；**联网失败时脚本自动跳过天气段并提示，其余分析照常**
- 依赖：`pip install -i https://pypi.tuna.tsinghua.edu.cn/simple xlrd openpyxl`（用户网络直连pypi会超时，须用清华镜像）
- 脚本输出：汽油/柴油损耗率、站点排名、温度温差、时段Vt、天气×时段交叉、罐位r

### Step 3 补充针对性分析（如需）
- 后五站点验收环节表现：按站点聚合实发/卸前/卸后温度、温差、损溢率Vt
- 进油节奏画像：站点汽油车次数、日均车次、单次进油量均值/中位、午后/凌晨卸油车次
- 高罐位分档：用卸前升数 p25/p75 分低/中/高罐位，对比损溢率Vt 及 Pearson r

### Step 4 生成 HTML 报告
按 `references/analysis_method.md` 第五节模板生成自包含 HTML（深色主题），章节：
1. 关键结论卡片
2. 汽油 vs 柴油口径对比（显式说明柴油盘盈稀释效应）
3. 汽油口径站点排名 + 后五站点
4. 武汉本地天气逐段
5. 卸油时段 × 天气交叉
6. 高罐位相关性
7. 调优建议（季节·站点特性·全站点·超标分层 A/B 档）

### Step 5 汇报要点（务必传达）
1. 全品损耗率被柴油盘盈掩盖 → 必须汽油单列口径
2. 未满月报表比损耗量是陷阱 → 用损耗率/日均
3. 高温日(≥35°C)与午后卸油损耗显著放大 → 时段错峰是可行抓手
4. 罐位与损耗无实质相关(|r|≤0.08)，主动配送下不可控，不作治理抓手
5. 超标站点分层建议：A档(连续超标且≥3‰)立即计量检定+时段错峰；B档拆小单量+错峰；考核口径切换汽油单列

## 注意事项
- .xls 用 xlrd 2.x 读取；.xlsx 用 openpyxl（read_only=True, data_only=True）
- **验收报表表头行不固定**（7月 R2/0索引1，8月 R1/0索引0），脚本自动探测；列名用子串匹配（"油品名称"优先于"油品"，避开"油品代码"）；排名"当期数据"列索引动态取
- 油品判断用"汽油"/"柴油"子串；乙醇汽油(E10)吸水易分层，8月高温蒸发快
- 天气取武汉(30.59,114.30)；若站点非武汉，用 `--lat/--lon` 传入
- 报告用中文、红色=损耗高/恶化、绿色=降耗/改善（中国金融色惯例）
- 未满月报表严禁比损耗量绝对值，用损耗率(‰)/日均
